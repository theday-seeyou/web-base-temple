## 本版约定

- 11 张默认应用表均包含 BIGINT UNSIGNED 自增主键 id。
- 创建时间 created_at、更新时间 updated_at 均为 DATETIME NOT NULL，默认 CURRENT_TIMESTAMP；updated_at 同时设置 ON UPDATE CURRENT_TIMESTAMP。
- 删除时间只有 deleted_at 一个字段，类型为 DATETIME NULL DEFAULT NULL。
- BaseModel 自动写入创建、更新时间并默认开启软删除；正常查询排除回收站，恢复时写入 NULL。
- migrate:create 默认生成 Core 迁移基类；createTable() 自动添加四个系统字段和删除时间索引。
- MD5 账号验证及旧密码升级 API 已移除。密码只接受 12–72 字节的 bcrypt，保留 bcrypt 成本参数更新。
- 安装迁移为干净基线，拒绝占用同名应用表的数据库，不提供旧字段转换。Phinx 自身的 migrations 记录表不属于应用表。

## 从空目录验收

先取出正式 Starter，再单独安装依赖，以便比对安装前后的项目文件：

```bash
composer create-project theday-seeyou/web-base-temple .codex-tmp/create-project-v050-final 0.5.0 --no-install --no-interaction --prefer-dist
cd .codex-tmp/create-project-v050-final
composer install --no-dev --classmap-authoritative --no-interaction --prefer-dist
```

随后复制 .env.example，连接独立测试数据库，执行两次 migrate:run，启动临时 HTTP
服务并运行 tests/integration.py。管理员由测试环境中的 admin:init 显式创建，没有固定默认密码。

本次使用 phpStudy PHP 8.2.9、MySQL 5.7。原工作区 .env 和既有数据库未用于写入验证。
PHP 8.1/8.2/8.3 的验证矩阵继续由 GitHub 工作流提供，本地结果不代表已在所有版本运行。

本报告对应 v0.5.0；旧版本的验收记录保留历史事实，不代表本版继续兼容旧密码或旧表结构。
