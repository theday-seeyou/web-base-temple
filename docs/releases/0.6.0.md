## 本次发布内容

- 后台顶部使用 Layui 按钮组实现连体“中文 / EN”分段选择，当前语言以深青色、白字和勾选标记显示。
- 语言偏好按管理员账号保存，跨模块、刷新和重新登录保持；超级管理员可以设置启用语言及默认语言。
- 未保存表单切换前提供继续编辑或放弃后切换；旧页面的异步请求通过语言上下文检查，返回 409 后停止执行控制器。
- 语言设置、公共后台控件及分类示例接入英文，前台访客的语言选择保持独立。
- 修正 GitHub Actions 在 job env 中使用 runner.temp 导致工作流无法启动的问题，将临时目录变量移至支持该上下文的步骤。

当前发布不包含完整后台英文翻译或数据库内容自动翻译。广告位、关于我们、联系我们、
站点配置等企业 CMS 模块，以及私有动态模型与模板能力，均未在本次新增实现。

## 正式安装与验证

从不存在的临时目录执行正式 Packagist 安装，没有自定义 repositories、本地 path 仓库或手工覆盖源码：

```bash
composer create-project theday-seeyou/web-base-temple .codex-tmp/create-project-v060-final 0.6.0 --no-install --no-interaction --prefer-dist
cd .codex-tmp/create-project-v060-final
composer install --no-dev --classmap-authoritative --prefer-dist --no-interaction
```

随后配置全新的独立数据库 `webbase_verify_v060_release`，执行两次 `php think migrate:run`，
启动端口 18461 的本地 HTTP 服务。HTTP 测试通过 CLI `admin:init` 初始化隔离测试账号。
测试连接与凭据仅在本地临时项目中使用，没有提交 .env、账号会话或数据库数据。

可在正式安装的隔离项目中按顺序复验：

```powershell
$env:WEBBASE_TEST_ISOLATED='1'
$env:WEBBASE_TEST_URL='http://127.0.0.1:18461'
python tests/integration.py
python tests/backend.py
python tests/website.py
python tests/admin_language.py
```

以上用例仅运行在 `webbase_verify_*` 或 `webbase_test_*` 数据库。
本次未连接真实云存储账号，未执行队列工作进程；生产项目及原有开发数据库没有参与写入验证。
