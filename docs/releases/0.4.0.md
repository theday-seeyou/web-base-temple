## 从空目录安装

实际执行成功的发行包安装命令：

```bash
composer create-project theday-seeyou/web-base-temple .codex-tmp/create-project-v040-final "0.4.0" --no-interaction --prefer-dist
```

随后按 README 复制环境配置，连接独立测试数据库，执行两次 migrate:run，
再运行 tests/integration.py。安装、迁移、管理员创建和 HTTP 验证均成功。
原工作区的环境文件与既有数据库未用于写入验证。
