# WebBase 0.5.1 后台与中英文首页验收

验收日期：2026-11-01。环境：Windows、PHP 8.2.9、MySQL 5.7。

正式包均已被 Packagist 收录：Core `v0.5.1`（`5e6a020`），
Starter `v0.5.1`（`ec651d4`）。旧版本标签未修改。

## 变更

- 用户、角色、菜单、字典、附件记录和分类示例默认使用 nullable DATETIME `deleted_at`。
- 角色、菜单、附件补齐真正的回收站、恢复和永久删除页面与接口。
- 角色回收保留授权节点，回收期间权限失效，恢复后权限生效；永久删除仅清理实际删除角色的节点。
- 菜单禁用和回收分离，补充循环关系、三级深度、子树删除及父节点恢复检查。
- 附件编辑、回收、恢复和永久删除按所有者隔离，清理重复记录改为软删除，保留实际文件。
- 用户模型序列化隐藏密码哈希，继续校验已登录会话的密码指纹。
- 修复数组语言参数、空队列参数造成的 HTTP 500。
- `/` 提供简单公开首页，通过 `?lang=zh-cn/en-us` 和独立的 30 天 `site_lang` Cookie 切换语言。
- Starter 最低依赖 Core `^0.5.1`，无本地 path 或自定义 Composer 仓库。

正式安装验收命令：

```bash
composer create-project theday-seeyou/web-base-temple .codex-tmp/create-project-v051-final 0.5.1 --no-install --no-interaction --prefer-dist
cd .codex-tmp/create-project-v051-final

```

随后连接独立的 `webbase_verify_v051_final` 数据库，显式执行迁移及管理员初始化，
启动本地 HTTP 服务，运行上述三个套件。迁移前缀验证另用两个空的隔离数据库。

本次只测试本地存储的真实上传下载；阿里云、七牛、腾讯云只验证配置表单渲染，
未连接真实云账号。任务验证不启动后台工作进程、不执行系统清理队列。
后台仍默认中文，不代表完整英文后台或数据库内容自动翻译。

开发数据库未用于迁移或写入验证。所有操作使用独立临时项目与隔离数据库。
